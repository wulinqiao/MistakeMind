# Prompt 版本记录

## b-1.0.0 2026-10-30

- 固定八类定义，区分主类别和知识点子标签，正常句不改写。
- 诊断同时产出错误依据、最小修改和三级提示；允许需要上下文。
- 修改题采用语病消除、原意保持、无新错误三个条件；接受不在参考中的合理修改。
- 诊断复核与评分复核独立生成；复核不同意时不强行通过。
- 系统消息包含输出 Schema，用户句子、答案、历史和候选结果作为 JSON 数据传递，明确不是指令。
- 不在 Prompt 中放入最终测试样本或其参考答案。Baseline 只有通用任务及同一结构规范。

变更规则：任何 Prompt 修改都提升版本，说明行为变化，并重新运行回归与新版本实验。旧 JSONL 不跨版本恢复。
