## 发现的问题与处理

原先 diagnose 即使配置密钥仍走 Mock；现在有明确 auto/mock/live 模式。原先原句只要含“通过”和“使”便判错；现在 Mock 只匹配固定样例，真实诊断由模型与复核完成。原先修改题逐字匹配且对象参考可能处理错误；现在标准参考直接判定，其他表达走语义评分与复核。

原先作答不保存关联诊断，历史类型为空；现在同事务保存并验证回滚。原先 Database 的连接上下文只提交或回滚，不关闭连接；这在 Windows 临时演示清理时实际触发文件占用，现已显式关闭所有 Database 自有连接并加入回归。原先 mastery_update.before 由事后正确率推算，错误答案会产生不正确的前值；现在从保存前统计读取。
