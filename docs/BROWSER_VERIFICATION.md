# 浏览器与完整应用验收记录

验收使用 Chromium 与 Playwright CLI，访问本机 127.0.0.1:8765。服务为 FastAPI 同源生产构建，独立 data/demo.db，AGENT_MODE=mock。界面中的题目、用户和成绩是开发演示数据，不代表真实模型评测或实际学习收益。

## 实际执行

| 检查 | 实际结果 |
| --- | --- |
| 首页加载 | 页面、导航、演示说明和练习条件正常显示 |
| 固定病句诊断 | 返回类型、错误片段、两个修改方向；可展开执行过程 |
| 正常句 | “今天的天空很蓝。”显示不是病句，不强制给修改 |
| 未覆盖句 | 显示需要上下文和“暂无法确认”，不把 false 字段当已确认正常句 |
| 分类题 | 显示题面和统一选项，题面不显示标准类别 |
| 错误作答 | 保存关联解析，显示原题病因与参考修改，标注开发样例来源 |
| 再答一次 | 点击重答后才由第 1 次变为第 2 次，正确回答显示累计正确率更新 |
| 精确推荐 | demo_02_2 错答后，网络请求 GET /api/questions/demo_01_2，取到同类的另一道题 |
| 推荐后刷新 | 地址栏更新 question_id=demo_01_2，刷新仍读取该题，未回到上一题 |
| 历史解析 | 显示原句、答案、类型、时间，展开已保存的本次解析 |
| 只看错题 | 3 条历史中正确 1 条、错误 2 条，筛选后总数为 2 |
| 历史持久化 | 刷新 /history 后重新查询，3 条记录仍可读取 |
| 画像 | 累计正确率、分类错误次数、近期平滑表现、探索推荐和每日趋势可见 |
| 小屏显示 | 390×844 视口检查 documentElement.scrollWidth=375，无横向溢出 |
| 生产构建 | npm run build 通过，同源刷新页面可用 |

首次验收发现推荐刷新回到旧题、重答计数提前增加和站点图标 404，均已修复后复测。推荐含未练类型探索，页面不将未练类型直接称为已确定的薄弱项。

截图与备用录屏交付于 deliverables/browser/。诊断、作答反馈、历史、画像、待复核与手机宽度均保留截图。录屏为离线演示，原始时长约 9 分 39 秒，包含操作间停顿；课堂讲解按单独的 5 分钟脚本组织。
